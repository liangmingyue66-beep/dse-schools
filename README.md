# DSE 内地高校筛选器

面向香港中学文凭考试（HKDSE）考生的择校小工具：帮你按 **分数 / 地区 / 院校名称 / 院校层次** 过滤 165 所内地高校的招生专业，并对照每个专业 **去年（2025/26）实录录取成绩**，快速圈出"自己够得着、值得看"的学校名单。

> 数据来源：官方《内地高校招收香港中学文凭考试学生计划指南（2026/27学年）》（香港教育局 / 学友社）。
> 本工具**只做筛选与陈列，不做"够不够 / 冲稳保"判断**，一切以原书及院校官方简章为准。

## 一、这是什么项目

- **给谁用**：正在准备 DSE 报读内地高校的学生和家长——不需要任何技术背景，打开网址就能用。
- **能做什么**：
  1. 按 **分数** 筛：填上中／英／数（预计）等级，只看"去年录取最低分 ≤ 你总分"的专业；
  2. 按 **地区** 筛：先选省份、再选城市（如广东 → 深圳）；
  3. 按 **院校名称** 筛：输入学校名直接回车跳转；
  4. 按 **层次** 筛：985 / 211 / 双一流 / 合作办学 等；
  5. 进校查看每个专业：去年录取 **最高 / 最低**（中英数三科原始等级 + 总分和）、录取人数、额外科目要求。
- **数据规模**：全国 23 省、165 所高校、3794 条专业数据（以 2025/26 实录成绩为主数据）。
- 技术形态：**纯静态网页**（无后端、无数据库），手机、电脑浏览器都能打开，数据全部随页面加载。

---

## 二、怎么使用（考生 / 家长看这段）

打开页面后会自动弹出"📖 如何使用"，三个方法即可上手：

- **方法一 · 院校查询**：顶部输入院校名称，回车直达该校详情。
- **方法二 · 分数查询**：选好中／英／数等级，点"✔ 应用分数筛选"，只保留去年最低分 ≤ 你总分的专业。
- **方法三 · 地区查询**：先选省份、再选城市；也可按 985/211/双一流、专业关键词组合筛选。

结果列表里：
- "进入该校 →" 看单校全部专业与去年实录分数；
- "无 2025/26 成绩" 的专业单独列在下部（多为首年招生等）；
- 分数只作对照参考，最终录取以官方为准。

随时可点页面右上角 **📖 使用指南** 重新查看说明。
