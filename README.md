# DSE 内地高校筛选工具 · 发布版（webv0 四件套）

本目录为**可直接部署的静态站点**，只含：
- `index.html` / `style.css` / `app.js` / `data.js`（数据由母表经 `make_web_data.py` 生成）

## 部署方式（任选其一）
- 静态托管：GitHub Pages / Netlify / Vercel / Cloudflare Pages，把本目录四个文件放站点根目录即可；
- 本地预览：直接双击 `index.html` 即可（数据用 `<script>` 注入，无需服务器）。

## 数据来源与合规（务必阅读）
- 数据来自官方《内地高校招收香港中学文凭考试学生计划指南（2026/27学年）》（香港教育局/学友社），**仅供学习交流，请勿商用或批量再分发**；
- 录取分数为 2025/26 学年度实录，可能含校长推荐计划/体艺类等特殊计划口径，一切**以原书及院校官方简章为准**；
- 额外科目要求信息可能有遗漏或解析差异（页面已常驻提示）；
- 版权归原出版机构所有。如数据使用引起任何版权顾虑，请下线本页面并删除数据。
- 本发布包**不含**原书 PDF、母表 CSV、抽取脚本及任何抓取材料。

## 数据内容
- 165 所高校（23 省级行政区）· 3794 条专业行（2025/26 实录成绩为主数据）
- 主要功能：省/市/层次/分数/专业名过滤；院校详情含 录取最高/最低 三科成绩与总分、额外科目要求等。
